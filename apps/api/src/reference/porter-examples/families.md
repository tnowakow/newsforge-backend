# Porter retrieval families

The signature index uses five structural families plus `spotlight-feature` as a content-emphasis alias. The runtime keeps the approved six-family vocabulary while mapping `spotlight-feature` to the dense lavender grid template.

- `feature-band`: birthday rail, executive cream panel, and a wide sky/berry feature band.
- `community-collage`: birthday/executive structure, navy outings/info panel, event recap, and clustered photos.
- `dense-lavender-grid`: many mid-sized modules, berry/lavender spotlight rail, and footer band.
- `editorial-light`: text-forward rhythm, fewer photos, or a long birthday list carrying the page.
- `photo-mosaic`: photo-led spread with a large mosaic and one narrow text rail.
- `spotlight-feature`: alias for resident-spotlight emphasis, rendered using the dense lavender grid grammar.

The CSV is the seeded k-nearest-neighbor index. The PDFs are intentionally not generated or fabricated here; they must be supplied as the actual reference assets before being committed.
